# BizTrack portfolio page

`biztrack-page.html` is the complete Custom HTML block for the published WordPress page at https://ikomeflow.com/biztrack/ (page ID 378). It preserves the existing page text and navigation and adds a responsive linked dashboard screenshot matching FlowTrack's presentation.

The screenshot at `dist/biztrack-dashboard-v1.jpg` was captured from BizTrack's **Explore demo** mode. All displayed business records are sample data. It is a 1425 × 1069 JPEG, approximately 80 KB. The app and page use the same public image at https://biztrack.ikomeflow.com/biztrack-dashboard-v1.jpg.

WordPress also has a copy as its featured image (media ID 399): https://ikomeflow.com/wp-content/uploads/2026/10/biztrack-dashboard-v1.jpg. Its title and alternative text identify the sample dashboard. This gives the WordPress page an appropriate image when shared. The application has matching Open Graph and Twitter image metadata.

Changing this repository does not automatically update WordPress. Apply the saved block through the page editor when changing the portfolio page. GitHub Pages deploys `dist/` after the repository's existing checks pass.
